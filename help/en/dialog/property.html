File Properties

User's Guide > Dialog Reference > File Properties

This dialog displays the information associated with the read file.

File Path
Path of the file.
Plugin
Plugin used in reading the file.
Max. Amplitude
Maximum amplitude value of waveform of the file.
Min. Amplitude
Manimum amplitude value of waveform of the file.
File Format
Type of file format. For Raw files, see File Formats.
Bits/Sample
Bits per sample (quantization bit depth) of the file.
Sampling Frequency
Sampling frequency of the file.
Number of Channels
Number of channels of the file.
